## ℹ️ Info about the program and how it was made

This program was originally a solution for a codewars problem. The code needed to calculate factorial of numbers that would normally cause an integer overflow. However I realized it can be made into an actual factorial calculator in C where you do not have to worry about overflow. This calculator can only do factorial and can be improved which I am planning to do and in the future I may merge this with the big numbers multiplication calculator and other parts to make a fully working calculator in C. The calculator for big numbers can be found here: https://github.com/coding-something/big-numbers-calculator-in-C

## ❓ How to use the calculator

Open the exe file or compile the master file and then run it. A terminal window will appear and you can input any number, then you will get the result and the program will give you an option to either exit or do another factorial. Just be aware that it is fragile and if you input anything else than pure numbers, you will get either a bug (ASCII values for chars for example) or the program will crash. Also there is still a limit for how big the numbers can be, but I am planning to fix that later on.
